🌐 STEP 1: 웹 배포 (30분, 무료)

┌─ GitHub 푸시 (5분)
│  cd /Users/macbook/Desktop/자동화
│  git remote add origin https://github.com/USERNAME/postai.git
│  git push -u origin main

├─ Streamlit Cloud (5분, 무료)
│  https://streamlit.io/cloud
│  → GitHub로 로그인 → postai 저장소 선택 → Deploy
│  ✨ URL: https://USERNAME-postai.streamlit.app

└─ Railway (5분, 무료)
   https://railway.app
   → GitHub로 로그인 → postai 저장소 선택 → Deploy
   ✨ URL: https://postai.up.railway.app

📱 STEP 2: 모바일 배포 (1-3일, $124 초기)

필수 계정 생성:
1️⃣  Expo (무료) → https://expo.dev
2️⃣  Apple Developer ($99) → https://developer.apple.com
3️⃣  Google Play ($25) → https://play.google.com/console

iOS 배포:
  cd /Users/macbook/Desktop/sns-mobile
  npm install -g eas-cli
  eas login
  eas build --platform ios
  eas submit --platform ios
  ⏳ Apple 심사 (1-3일)
  ✨ App Store에 나타남

Android 배포:
  eas build --platform android
  eas submit --platform android
  ⏳ Google 심사 (1-3시간)
  ✨ Play Store에 나타남
