Stripe 결제 설정이 필요합니다

아래 단계를 따라 Stripe를 설정하면
{{ plan }} 플랜 결제가 활성화됩니다.

현재 테스트 모드입니다 — 실제 결제가 이루어지지 않습니다
1

Stripe 계정 만들기

stripe.com에서 무료 계정을 만드세요. 한국 사업자도 가입 가능합니다.

2

API 키 복사

Stripe 대시보드 → Developers → API keys에서 Secret key를 복사하세요.

sk_test_... (테스트) 또는 sk_live_... (실제)
3

구독 상품 & 가격 생성

Stripe 대시보드 → Products → Add product에서 스타터(₩19,900)와 프로(₩49,900) 구독 상품을 만드세요. 각 상품의 Price ID(price_...)를 복사합니다.

4

환경변수 설정 후 서버 재시작

web/ 폴더에 .env 파일을 만들어 아래와 같이 입력하세요:

SECRET_KEY=랜덤-비밀키-입력 STRIPE_SECRET_KEY=sk_test_... STRIPE_WEBHOOK_SECRET=whsec_... STRIPE_STARTER_PRICE_ID=price_... STRIPE_PRO_PRICE_ID=price_...
5

웹훅 등록 (선택, 프로덕션 필수)

Stripe 대시보드 → Webhooks → Add endpoint에서 아래 URL을 등록하세요:

https://yourdomain.com/stripe-webhook

이벤트: checkout.session.completed, customer.subscription.deleted, invoice.payment_failed
